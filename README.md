# Andorra Private

Quiet-luxury magazine and residency/relocation directory for [privateandorra.com](https://privateandorra.com).

## Stack

Astro 7. Forms go to Formspree. Contact: `hello@privateandorra.com`.

## Commands

```sh
npm run dev
npm run build
npm run preview
```

Directory and parish copy lives in `src/data/`. Do not invent firms, telephone numbers, law figures, or property listings.

See `AGENTS.md` for page map and conventions.
